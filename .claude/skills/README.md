# Skills for Claude Code in this repo

| Skill | Use it for | Source |
|---|---|---|
| `medisave-ios` | Every ticket: architecture (MVVM, feature folders, SOLID), workflow, tests, PR checklist | Written for MediSave |
| `swiftui-pro` | Reviewing SwiftUI code for modern API, accessibility, layout and performance | [twostraws/SwiftUI-Agent-Skill](https://github.com/twostraws/SwiftUI-Agent-Skill) @ f9800713, MIT, Paul Hudson |
| `swift-concurrency` | Swift 6 concurrency errors, actors, Sendable, async code | [AvdLee/Swift-Concurrency-Agent-Skill](https://github.com/AvdLee/Swift-Concurrency-Agent-Skill) @ d5770817, MIT, Antoine van der Lee |

The two third-party skills are vendored unchanged (minus icons) with their licenses. Where they disagree with `medisave-ios`, `medisave-ios` wins for this project (for example, the deployment target is iOS 17, not the newest iOS).
