## MS-155 · Rename the app, the code and the repository to Dentory
meta: milestone=M0; priority=P0; type=tech; area=platform; size=3; frames=f1; screens=signin; prd=§1; depends=MS-110,MS-114

### Why
Grigor bought `dentory.ca` on 2026-10-17 and renamed the product from MediSave to Dentory (MS-100 D15 and D16). The old name sits in 66 files of the repository: the Xcode project, targets, bundle ids, folders, Swift types, the Makefile, the lint config, the local Supabase config, the house skill, the reviewer agent and the root docs. This is the only rename ticket that touches code. MS-156 does the docs, the design files, the ticket sources and the issues; MS-157 the services outside the repository. Do it before any further feature ticket: after the first App Store upload the bundle id and the app record are permanent, and every merged feature adds files that would need the rename too.

### Names (MS-100 D16)
- Product and display name **Dentory**. Bundle id `ca.dentory.app`; test bundles `ca.dentory.app.tests` and `ca.dentory.app.uitests`. The bundle id is Claude's default (reverse of the domain) until Grigor confirms it with his Apple Developer team; change it in `project.yml` only if he picks another.
- Repository `grigorhello/Dentory`. Xcode project, scheme and app target `Dentory`; test targets `DentoryTests` and `DentoryUITests`; source folders with the same names. Local Supabase project id `Dentory`. Skill `dentory-ios`.
- Kept on purpose: the `MS-` ticket ids; the `MS` prefix on design-system types (`MSColor`, `MSButton`, `MSSheet`: from now on it is the design-system prefix, not short for the old name; say so in the skill); the hosted Supabase project ref; the Mac checkout path `/Users/grigorgrigoryan/Documents/Personal/MediSave` (the Remote Control approval is bound to it); the git history (use `git mv`).

### Steps, in this order
1. **Repository.** From the Mac, where `gh` is signed in as grigorhello: `gh repo rename Dentory -R grigorhello/MediSave`. GitHub keeps issues, pull requests and CI and redirects every old URL and clone address, so pinned links in the issues keep working. Then `git remote set-url origin https://github.com/grigorhello/Dentory.git` in the checkout if `gh` did not do it, and tell Grigor to point the Claude project at the renamed repository (MS-157 lists it). Do this step first and alone, before the branch for the rest.
2. **Folders and targets.** `git mv MediSave Dentory`, `git mv MediSaveTests DentoryTests`, `git mv MediSaveUITests DentoryUITests`, `git mv Dentory/App/MediSaveApp.swift Dentory/App/DentoryApp.swift` (`struct DentoryApp: App`), `git mv MediSave.xcodeproj/project.xcworkspace/xcshareddata/swiftpm/Package.resolved` to the same path under `Dentory.xcodeproj` (the rest of the project file is generated and ignored). `@testable import MediSave` becomes `@testable import Dentory` in every test file (15 today).
3. **`project.yml`.** `name: Dentory`, `bundleIdPrefix: ca.dentory`, the three targets renamed, `PRODUCT_NAME: Dentory`, `PRODUCT_BUNDLE_IDENTIFIER` for app, tests and UI tests as above, `INFOPLIST_KEY_CFBundleDisplayName: Dentory`, `INFOPLIST_FILE: Dentory/Resources/Info.plist`, `TEST_HOST` and `TEST_TARGET_NAME`, the scheme and its test targets. Then `make project`.
4. **Build tooling.** `Makefile`: `SCHEME := Dentory`, `PROJECT := Dentory.xcodeproj`, `-only-testing:DentoryTests`, `-only-testing:DentoryUITests`, `DB_CONTAINER ?= supabase_db_Dentory`. `.swiftlint.yml`: the three included paths and the two design-system exclusion paths. Check `.github/workflows/ci.yml` and `.github/pull_request_template.md` for paths (none today).
5. **Code and strings.** `SignInView`: the title reads "Dentory" (frame f1 still shows the old wordmark; D15 overrides it). `NetworkMonitor`: queue label `ca.dentory.network-monitor`. Doc comments that say MediSave in `AppDependencies`, `MSButtonStyle`, `MSColor`, `MSSheet` and the test support files. Any UI test or snapshot that asserts the old title. `git grep -in medisave -- '*.swift'` must come back empty.
6. **Local Supabase.** `supabase/config.toml`: `project_id = "Dentory"`, which renames the Docker containers; run `make db-stop` on the old name before the change, then `make db-start db-reset seed-demo db-test`. pgTAP fixtures: the `@medisave.test` addresses in `supabase/tests/database/05_access_test.sql` become `@dentory.test`; the comment at the top of `supabase/seed-demo.sql` names the prototype file by its new name from MS-156 (`design/project/Dentory Mobile.dc.html`). Migrations, seed and Edge Functions carry no name; do not add a migration.
7. **House rules.** `git mv .claude/skills/medisave-ios .claude/skills/dentory-ios`; in `SKILL.md` set `name: dentory-ios`, rename the product and the folders in the text and the folder tree, and add one line under the design-system section that `MS` is the design-system prefix. Update every reference: `CLAUDE.md` (title, intro, skill path, `Dentory/Core/DesignSystem`, `Dentory.xcodeproj`), `README.md`, `.claude/skills/README.md`, `.claude/agents/pr-reviewer.md` (`-R grigorhello/Dentory`, "a Dentory pull request", the skill name). Also replace the name in `.github/pull_request_template.md` if it appears.
8. **Verify** with the acceptance criteria below, open the PR with `Closes #N` and simulator screenshots of the sign-in screen and the home screen icon label, and run the review loop. Then move straight to MS-156 in the same session.

### Out of scope
`docs/`, `design/`, the ticket sources, the GitHub issue bodies and the Notion board (MS-156). Hosted Supabase, Apple, the Claude project, DNS and third-party accounts (MS-157). Wordmark, app icon and visual identity: nothing exists yet; MS-152 draws the plain wordmark with the new name.

### Acceptance criteria
- [ ] `make project lint build test` is green locally with `WARNINGS_AS_ERRORS=YES`, and CI is green on the pull request in `grigorhello/Dentory`.
- [ ] On the iPhone 16 simulator the app installs as "Dentory" with bundle id `ca.dentory.app` (`xcrun simctl listapps booted | grep -A3 dentory`), the sign-in title reads "Dentory", and `make uitest` passes.
- [ ] `make db-start db-reset seed-demo db-test` passes with the `supabase_db_Dentory` container.
- [ ] `git grep -il medisave -- ':!design' ':!docs' ':!*.png'` prints nothing.
- [ ] The repository is `github.com/grigorhello/Dentory`, `gh pr view` on the Mac resolves against it, and `git remote -v` shows the new address.
