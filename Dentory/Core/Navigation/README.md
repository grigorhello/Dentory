The app shell (MS-103): `AppRouter` (selected tab and one typed path per tab), `ToastCenter` and its overlay, `MSSheet` and `SheetList`, `PinnedPrimaryBar`, the root and pushed screen headers with the controls a screen pins under them (`pinned:`, such as Inventory's search field and chips), `ContentColumn`, `OfflineBanner` and the `.adminOnly()` modifier. Features use these; they never draw their own chrome.
